# 查岗MCP 添加 iPhone 远程遥控（"回来"/"睡觉"）

通过 **SMTP 邮件 → iPhone 邮件 App → 快捷指令自动化**，让 AI 助手远程控制 iPhone：

- 主题 `回来` → 手机自动切回指定 App（如 Kelivo）
- 主题 `睡觉` → 手机直接锁屏
- 主题 `测试` → 只发邮件验证链路

## 原理

```text
AI 助手
  └─ send_email.py（SMTP 发邮件，主题=命令）
      └─ 163 邮箱
          └─ iPhone 邮件 App 收到
              └─ 快捷指令自动化（收到指定主题触发）
                  └─ 切回 App / 锁屏
```

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `send_email.py` | 发邮件脚本（SMTP 发命令） |
| `server.py` | 查岗MCP 完整示例（含 send_iphone_cmd 工具） |
| `教程-完整版.md` | 完整图文教程 |

## 快速开始

1. 163 邮箱网页版开启 SMTP 服务，生成**客户端授权码**（不是登录密码）
2. 把 `send_email.py` 里的 `PASSWORD` 换成你的授权码
3. iPhone 快捷指令：新建自动化 → App 邮件 → 收到来自自己邮箱、主题为 `回来` 的邮件 → 打开目标 App；主题 `睡觉` → 锁定屏幕
4. 在查岗 MCP 的 `server.py` 里加上 `send_iphone_cmd` 工具（见教程）
5. 重启 MCP，Kelivo 断开重连即可

## 注意

- 授权码是敏感信息，**不要提交到公开仓库**，用环境变量或本地配置文件管理
- `mcp.run()` 必须放在所有 `@mcp.tool()` 定义**之后**，否则后面的工具不注册
